# Mathieu group M~24~

<!-- AI assistance: OpenAI Codex prepared this page from the ATLAS and pyatlas verification files. -->

The presentation and maximal subgroup data come from the
[ATLAS of Group Representations](https://brauer.maths.qmul.ac.uk/Atlas/v3/spor/M24/).
The claimed order is $|\mathrm{M}_{24}| = 244,823,040$.

## Presentation

$$
    \mathrm{M}_{24} = \langle a,b \mid a^2 = b^3 = (ab)^{23}
    = [a,b]^{12} = [a,bab]^5
    = (ababab^{-1})^3(abab^{-1}ab^{-1})^3
    = (ab(abab^{-1})^3)^4 = 1 \rangle
$$

The scripts also include $[a,b^{-1}abab]^5=1$, which is marked as redundant
in the [ATLAS Magma file](https://brauer.maths.qmul.ac.uk/Atlas/spor/M24/mag/M24G1-P1.M).
We do not verify that this relation is redundant here.
