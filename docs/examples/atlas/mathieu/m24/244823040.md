## Claim

Let $H$ be the trivial subgroup. We verify that the
[presentation of M~24~](index.md#presentation), including the additional
relation described above, defines a group of order

$$
    [\mathrm{M}_{24}:H] = |\mathrm{M}_{24}| = 244,823,040.
$$

## The code

The following script includes the full presentation and can be run on its own.
It uses only the generators `a` and `b`; inverses are expressed using
$a^{-1}=a$ and $b^{-1}=b^2$.

<details markdown>
<summary>Code</summary>

```python
from datetime import timedelta

from libsemigroups_pybind11 import (
    Presentation,
    ToddCoxeter,
    congruence_kind,
    presentation,
)
from libsemigroups_pybind11.words import parse_relations

# The empty word and a^2 = b^3 = 1 allow this presentation to define a group.
p = Presentation("ab")
p.contains_empty_word(True)

# Add the defining relations
presentation.add_rule(p, parse_relations("a^2"), "")
presentation.add_rule(p, parse_relations("b^3"), "")
presentation.add_rule(p, parse_relations("(ab)^23"), "")
presentation.add_rule(p, parse_relations("(abbab)^12"), "")
presentation.add_rule(p, parse_relations("(abbabbabab)^5"), "")
presentation.add_rule(p, parse_relations("(abababb)^3(ababbabb)^3"), "")
presentation.add_rule(
    p, parse_relations("(abbabbababbabab)^5"), ""
)  # redundant, but quite useful.
presentation.add_rule(p, parse_relations("(ab(ababb)^3)^4"), "")

if __name__ == "__main__":
    # Enumerate the whole group, without imposing any subgroup generators.
    tc = ToddCoxeter(congruence_kind.twosided, p)
    tc.strategy(tc.options.strategy.felsch)
    tc.def_version(tc.options.def_version.two)
    tc.use_relations_in_extra(True)
    tc.def_max(10000)
    tc.lower_bound(244823040)
    # Cap the reporting interval at one second.
    tc.report_every(timedelta(seconds=1))

    actual_order = tc.number_of_classes()
    print(f"The size of the group defined by the presentation is {actual_order}")
    if actual_order != 244823040:
        raise RuntimeError(f"expected order 244823040, got {actual_order}")
```

</details>
