## Presentation

$$
    \mathrm{M}_{11} = \langle a,b \mid a^2 = b^4 = (ab)^{11} = (ab^2)^6 = ababab^{-1}abab^2ab^{-1}abab^{-1}ab^{-1} = 1 \rangle
$$

with $|\mathrm{M}_{11}| = 7,920$.
