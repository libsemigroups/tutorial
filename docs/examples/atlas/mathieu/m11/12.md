## Claim

If

$$
    H = \langle a,\ (bab)^2 \rangle \cong L_2(11),
$$

then

$$
    [\mathrm{M}_{11}:H] = 12.
$$

We verify the claimed index, but not the claimed isomorphism type.

## The code

The following script includes the full presentation and can be run on its own.

<details markdown>
<summary>Code</summary>

```python
from datetime import timedelta

from libsemigroups_pybind11 import (
    Presentation,
    ToddCoxeter,
    congruence_kind,
    presentation,
)
from libsemigroups_pybind11.words import parse_relations

p = Presentation("abAB")
p.contains_empty_word(True)
presentation.add_inverse_rules(p, "ABab")

presentation.add_rule(p, parse_relations("a^2"), "")
presentation.add_rule(p, parse_relations("b^4"), "")
presentation.add_rule(p, parse_relations("(ab)^11"), "")
presentation.add_rule(p, parse_relations("(ab^2)^6"), "")
presentation.add_rule(p, parse_relations("ababaBabab^2aBabaBaB"), "")

# L2(11), order 660, expected index 12.
# Generators: a, (bab)^2.
# Source: https://brauer.maths.qmul.ac.uk/Atlas/spor/M11/words/M11G1-max2W1
tc = ToddCoxeter(congruence_kind.onesided, p)
for word in ("a", "babbab"):
    tc.add_generating_pair(word, "")

tc.report_every(timedelta(microseconds=1))

actual_index = tc.number_of_classes()
print(f"The index of L2(11) is {actual_index}")
if actual_index != 12:
    raise RuntimeError(f"expected index 12, got {actual_index}")
```
