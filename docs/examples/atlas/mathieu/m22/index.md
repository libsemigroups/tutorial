## Presentation

$$
    \mathrm{M}_{22} = \langle a,b \mid a^2 = b^4 = (ab)^{11} = (ab^2)^5 = [a,bab]^3 = (ababab^{-1})^5 = 1 \rangle
$$

with $|\mathrm{M}_{22}| = 443,520$.
