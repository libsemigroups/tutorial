## Claim

Let $u$ and $v$ be the two subgroup words listed in the code below. If

$$
    H = \langle u,v \rangle \cong 2^3:L_3(2),
$$

then

$$
    [\mathrm{M}_{22}:H] = 330.
$$

We verify the claimed index, but not the claimed isomorphism type. In the code,
uppercase letters denote inverses, so `A` represents $a^{-1}$ and `B`
represents $b^{-1}$.

## The code

The following script includes the full presentation and can be run on its own.

<details markdown>
<summary>Code</summary>

```python
from datetime import timedelta

from libsemigroups_pybind11 import (
    Presentation,
    ToddCoxeter,
    congruence_kind,
    presentation,
)
from libsemigroups_pybind11.words import parse_relations

# Enable the empty word and inverses so the presentation defines a group.
p = Presentation("abAB")
p.contains_empty_word(True)
presentation.add_inverse_rules(p, "ABab")

# Add the defining relations
presentation.add_rule(p, parse_relations("a^2"), "")
presentation.add_rule(p, parse_relations("b^4"), "")
presentation.add_rule(p, parse_relations("(ab)^11"), "")
presentation.add_rule(p, parse_relations("(ab^2)^5"), "")
# [a, bab] = a^-1 (bab)^-1 a (bab).
presentation.add_rule(p, parse_relations("(ABABabab)^3"), "")
presentation.add_rule(p, parse_relations("(ababaB)^5"), "")

# 2^3:L3(2), order 1344, expected index 330.
# Source: https://brauer.maths.qmul.ac.uk/Atlas/spor/M22/words/M22G1-max6W1
# ATLAS output words simplified using a^2 = b^4 = 1; B denotes b^-1.
tc = ToddCoxeter(congruence_kind.onesided, p)
for word in (
    "a",
    "bbaBabbaBabbaBaBaBabababababbababbababb",
):
    tc.add_generating_pair(word, "")

tc.report_every(timedelta(milliseconds=8))

actual_index = tc.number_of_classes()
print(f"The index of 2^3:L3(2) is {actual_index}")
if actual_index != 330:
    raise RuntimeError(f"expected index 330, got {actual_index}")
```
