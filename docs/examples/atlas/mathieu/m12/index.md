## Presentation

$$
    \mathrm{M}_{12} = \langle a,b \mid a^2 = b^3 = (ab)^{11} = [a,b]^6 = (ababab^{-1})^6 = 1 \rangle
$$

with $|\mathrm{M}_{12}| = 95,040$.
