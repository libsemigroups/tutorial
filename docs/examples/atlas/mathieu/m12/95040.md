## Claim

Let $H$ be the trivial subgroup. We verify that the
[presentation of M~12~](index.md#presentation) defines a group of order

$$
    [\mathrm{M}_{12}:H] = |\mathrm{M}_{12}| = 95,040.
$$

## The code

The following script includes the full presentation and can be run on its own.

<details markdown>
<summary>Code</summary>

```python
from datetime import timedelta

from libsemigroups_pybind11 import (
    Presentation,
    ToddCoxeter,
    congruence_kind,
    presentation,
)
from libsemigroups_pybind11.words import parse_relations

# Enable the empty word and inverses so the presentation defines a group.
p = Presentation("abAB")
p.contains_empty_word(True)
presentation.add_inverse_rules(p, "ABab")

# Add the defining relations
presentation.add_rule(p, parse_relations("a^2"), "")
presentation.add_rule(p, parse_relations("b^3"), "")
presentation.add_rule(p, parse_relations("(ab)^11"), "")
presentation.add_rule(p, parse_relations("(ABab)^6"), "")
presentation.add_rule(p, parse_relations("(ababaB)^6"), "")

tc = ToddCoxeter(congruence_kind.twosided, p)
tc.report_every(timedelta(milliseconds=5))
tc.run_for(timedelta(seconds=10))

if not tc.finished():
    raise RuntimeError("The enumeration did not finish within 10 seconds")

actual_order = tc.number_of_classes()
print(f"The size of the group defined by the presentation is {actual_order}")
if actual_order != 95040:
    raise RuntimeError(f"expected order 95040, got {actual_order}")
```
