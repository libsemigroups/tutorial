## Claim

Let $u$ and $v$ be the two subgroup words listed in the code below,
for class II. If

$$
    H = \langle u,v \rangle \cong \mathrm{M}_{11},
$$

then

$$
    [\mathrm{M}_{12}:H] = 12.
$$

We verify the claimed index, but not the claimed isomorphism type. In the code,
uppercase letters denote inverses, so `A` represents $a^{-1}$ and `B`
represents $b^{-1}$.

## The code

The following script includes the full presentation and can be run on its own.

<details markdown>
<summary>Code</summary>

```python
from datetime import timedelta

from libsemigroups_pybind11 import (
    Presentation,
    ToddCoxeter,
    congruence_kind,
    presentation,
)
from libsemigroups_pybind11.words import parse_relations

# Enable the empty word and inverses so the presentation defines a group.
p = Presentation("abAB")
p.contains_empty_word(True)
presentation.add_inverse_rules(p, "ABab")

# Add the defining relations
presentation.add_rule(p, parse_relations("a^2"), "")
presentation.add_rule(p, parse_relations("b^3"), "")
presentation.add_rule(p, parse_relations("(ab)^11"), "")
presentation.add_rule(p, parse_relations("(ABab)^6"), "")
presentation.add_rule(p, parse_relations("(ababaB)^6"), "")

# M11 (class ii), order 7920, expected index 12.
# Source: https://brauer.maths.qmul.ac.uk/Atlas/spor/M12/words/M12G1-max2W1
# ATLAS output words simplified using a^2 = b^3 = 1; B denotes b^-1.
tc = ToddCoxeter(congruence_kind.onesided, p)
for word in (
    "a",
    "babaBababaBabaBaBabababaBabaBaBaBaBaB",
):
    tc.add_generating_pair(word, "")

tc.report_every(timedelta(microseconds=1200))

actual_index = tc.number_of_classes()
print(f"The index of M11 (class ii) is {actual_index}")
if actual_index != 12:
    raise RuntimeError(f"expected index 12, got {actual_index}")
```
