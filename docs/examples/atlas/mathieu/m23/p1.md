## Claim

$$
    \mathrm{M}_{23} = \langle a, b \mid a^2 = b^4 = (ab)^{23}
    = (ab^2)^6 = [a, b]^6 = (abab^{-1}ab^2)^4
    = (ab)^3ab^{-1}ab^2(abab^{-1})^2(ab)^3(ab^{-1})^3
    = (abab^2)^3(ab^2ab^{-1})^2abab^2abab^{-1}ab^2 = 1 \rangle
$$

Let $H$ be the trivial subgroup. Including the additional relation described
above, the presentation used by the script defines a group of order

$$
    [\mathrm{M}_{23}:H] = |\mathrm{M}_{23}| = 10,200,960.
$$

## The code

The following script includes the full presentation and can be run on its own.

<details markdown>
<summary>Code</summary>

```python
from datetime import timedelta

from libsemigroups_pybind11 import (
    Presentation,
    ToddCoxeter,
    congruence_kind,
    presentation,
)
from libsemigroups_pybind11.words import parse_relations

# Enable the empty word and inverses so the presentation defines a group.
p = Presentation("abAB")
p.contains_empty_word(True)
presentation.add_inverse_rules(p, "ABab")

# Add the defining relations
presentation.add_rule(p, parse_relations("a^2"), "")
presentation.add_rule(p, parse_relations("b^4"), "")
presentation.add_rule(p, parse_relations("(ab)^23"), "")
presentation.add_rule(p, parse_relations("(ab^2)^6"), "")
presentation.add_rule(p, parse_relations("(ABab)^6"), "")
presentation.add_rule(p, parse_relations("(abaBab^2)^4"), "")
presentation.add_rule(p, parse_relations("(ab)^3aBab^2(abaB)^2(ab)^3(aB)^3"), "")
presentation.add_rule(
    p, parse_relations("(abab^2ab^2)^6"), ""
)  # Is redundant, but very useful.
presentation.add_rule(p, parse_relations("(abab^2)^3(ab^2aB)^2abab^2abaBab^2"), "")
presentation.replace_subword(p, "A", "a")
p.alphabet("Bab")

tc = ToddCoxeter(congruence_kind.twosided, p)
tc.strategy(ToddCoxeter.options.strategy.felsch)
tc.report_every(timedelta(seconds=1.6))

actual_order = tc.number_of_classes()
print(f"The size of the group defined by the presentation is {actual_order}")
if actual_order != 10200960:
    raise RuntimeError(f"expected order 10200960, got {actual_order}")
```
