## Claim

Let $u$ and $v$ be the two subgroup words listed in the code below. If

$$
    H = \langle u,v \rangle \cong \mathrm{M}_{11},
$$

then

$$
    [\mathrm{M}_{23}:H] = 1,288.
$$

We verify the claimed index, but not the claimed isomorphism type. In the code,
uppercase letters denote inverses. The presentation replaces `A` by `a`,
since $a^2=1$, and `B` represents $b^{-1}$.

## The code

The following script includes the full presentation and can be run on its own.

<details markdown>
<summary>Code</summary>

```python
from datetime import timedelta

from libsemigroups_pybind11 import (
    Presentation,
    ToddCoxeter,
    congruence_kind,
    presentation,
)
from libsemigroups_pybind11.words import parse_relations

# Enable the empty word and inverses so the presentation defines a group.
p = Presentation("abAB")
p.contains_empty_word(True)
presentation.add_inverse_rules(p, "ABab")

# Add the defining relations
presentation.add_rule(p, parse_relations("a^2"), "")
presentation.add_rule(p, parse_relations("b^4"), "")
presentation.add_rule(p, parse_relations("(ab)^23"), "")
presentation.add_rule(p, parse_relations("(ab^2)^6"), "")
presentation.add_rule(p, parse_relations("(ABab)^6"), "")
presentation.add_rule(p, parse_relations("(abaBab^2)^4"), "")
presentation.add_rule(p, parse_relations("(ab)^3aBab^2(abaB)^2(ab)^3(aB)^3"), "")
presentation.add_rule(
    p, parse_relations("(abab^2ab^2)^6"), ""
)  # Is redundant, but very useful.
presentation.add_rule(p, parse_relations("(abab^2)^3(ab^2aB)^2abab^2abaBab^2"), "")
presentation.replace_subword(p, "A", "a")
p.alphabet("Bab")

# M11, order 7920, expected index 1288.
# Source: https://brauer.maths.qmul.ac.uk/Atlas/spor/M23/words/M23G1-max5W1
# ATLAS output words simplified using a^2 = b^4 = 1; B denotes b^-1.
tc = ToddCoxeter(congruence_kind.onesided, p)
for word in (
    "bbabbabaBabbabab",
    "b",
):
    tc.add_generating_pair(word, "")

tc.report_every(timedelta(milliseconds=2.2))

actual_index = tc.number_of_classes()
print(f"The index of M11 is {actual_index}")
if actual_index != 1288:
    raise RuntimeError(f"expected index 1288, got {actual_index}")
```
